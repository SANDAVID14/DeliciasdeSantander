# Flujo de Trabajo Git y GitHub

A petición del usuario, cada vez que se realice un cambio, adición o ajuste en los archivos del proyecto:
1. Ejecutar `git add .` (o los archivos específicos modificados).
2. Crear un commit con un mensaje claro y descriptivo en español (ej. `git commit -m "feat(pedidos): ..."`, `git commit -m "fix: ..."`).
3. Enviar los cambios al repositorio remoto en GitHub mediante `git push origin master`.
